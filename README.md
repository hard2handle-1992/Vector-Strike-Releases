# Vector Strike

Vector Strike is a car-and-ball arena game built with Unreal Engine 5: rocket-boosted cars, an oversized ball, and seven stadiums. This repository holds the playable Windows builds. The source code is not published here.

## Download and play

1. Open the [latest release](../../releases/latest) and download the `.zip` file.
2. Extract the whole zip. Keep the folder layout as it is.
3. Run `VectorStrike.exe` in the top folder.

Windows 10 or 11, 64-bit. If the game stops with a missing-DLL message, install Microsoft's "Visual C++ 2015-2022 Redistributable (x64)". The game is not code-signed, so Windows SmartScreen may ask before running it.

## What is in the game

- Soccer, Hoops, Snow Day and Rumble modes, with free play, exhibition matches against bots and training.
- Seven arenas, from a floodlit night stadium to a canyon in daylight, with a crowd, LED ribbons and live scoreboards.
- LAN play: host a room or join one on the same network.

These are preview builds. Expect rough edges.
